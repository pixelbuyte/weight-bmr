# PulseFuel BMR

A premium BMR and TDEE calculator built with React, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

## Features

- Live Harris-Benedict BMR calculation with gender, age, height, and weight inputs.
- Metric/imperial unit toggle with automatic kg/lb and cm/in conversions.
- Activity selector for TDEE and daily calorie needs.
- Keto mode with 20-30% calorie deficit recommendations and 75/20/5 macro targets.
- Responsive dark luxury fitness UI with animated metric cards.
- Three.js avatar that morphs by BMI and highlights muscle activation by activity level.
